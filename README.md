Chatbot_Emotion-classification


프로젝트기간 : 2025/06/17~ 2025/10/15

인원및목표 : 4명/ 허깅페이스를 활용하여 긍,부정 분류하는 Chatbot 구현

주요역할 : 데이터전처리/ LLM모델구축/ AWS 웹서비스 배포
